# 辐照实验剂量见证台账

浏览器本地持久化的哈希链补录台账：同一工作站多个标签页并发补录剂量时，保证
**无重号、无分叉、断链可察觉且可定位**。零第三方依赖，仅需 Node.js ≥ 20。

## 运行

```bash
# 本地
npm start                 # 默认 0.0.0.0:8080
PORT=9000 npm start       # 可配置宿主端口
curl localhost:8080/healthz

# Docker Compose
docker compose up app               # 页面 + /healthz，宿主端口由 HOST_PORT 配置（默认 8080）
docker compose run --rm verify      # 单次验收服务：场景复算 + 测试 + 构建检查 + HTTP 冒烟
docker compose up verify            # 同上，verify 按退出码结束（0 成功 / 非 0 失败），不常驻

# 脱离容器的完整验收
npm run verify
```

## 数据模型

一条记录（块）：

```json
{
  "seq": 3,
  "instrument": "ACC-01",
  "dose": 25,
  "operator": "张工",
  "opId": "辐照单-2026-0923-07",
  "prevDigest": "上一条记录的 SHA-256（第 1 条为 64 个 0 的创世锚点）",
  "digest": "本条 SHA-256"
}
```

- **规范化业务内容**：字符串字段去首尾空白且非空；剂量必须是非负安全整数；
  规范化 JSON 键按字典序排序，跨端字节一致。
- **摘要配方**：`SHA-256("sha256-v1\n" + seq + "\n" + prevDigest + "\n" + canonicalJson)`。
- **链头锚点**（独立于链数组持久化）：`{seq, digest}`，用于察觉“尾部记录被整体删除”
  ——仅靠块内容无法自证尾部缺失。

## 并发与崩溃语义

`lib/storage.js` 在 localStorage 上实现：

1. **跨标签页互斥锁**：随机令牌 + 稳定窗口仲裁 + 心跳续租 + TTL 抢占，
   提交全程持锁，多标签页并发在浏览器本地持久化层串行裁决。
2. **意图日志两段提交**：先写意图（内容、序号、前序摘要），再
   `链追加 → 锚点推进 → 清意图`。
3. **刷新 / 中途关页**：标签页关闭即停心跳，锁按 TTL 失效；重开时持锁复算：
   - 意图对应的记录已完整落库 → 记录有效，清意图（重试走幂等返回原记录）；
   - 记录不存在（崩溃于意图后/链写入前后）→ 完全无记录，清意图，可重新提交；
   - 唯一合法在途窗口“链已写、锚点未推进 1 条”→ 全链复算通过后补齐锚点。
   即：**只能留下完整记录或完全无记录**。
4. **幂等 / 冲突**（锁内先查 `opId`）：
   - 同 `opId` + 规范化后同内容（含迟到提交、重复点击）→ 返回原记录，链一字节不变；
   - 同 `opId` + 异内容 → 稳定拒绝 `OPID_CONFLICT`，可信链头不变。
5. **断链检测与隔离**：任一次提交前、storage 事件、手动“从创世复算”都会
   从创世锚点逐条重算。发现记录缺失（断号/尾部缺失）、内容被改、前序摘要不符、
   摘要被改、锚点不符时：定位**首个坏序号**，把其后记录移入隔离后缀，
   冻结追加，并保留、展示**最后一个可信链头**。

## 页面

- 表单：仪器、整数剂量、操作人、操作标识；提交前实时预览“当前摘要”。
- 链状态：连续序号、前序摘要、最后可信链头。
- 本标签页提交状态：排队/写入中（未落库）、已落库、幂等返回原记录、被拒绝/冻结；
  刷新后按链上复算结果把在途项归位为“已落库”或“未落库已回滚”。
- 断链横幅：首个坏序号、原因、隔离条数、可信链头；隔离后缀单独成表展示。
